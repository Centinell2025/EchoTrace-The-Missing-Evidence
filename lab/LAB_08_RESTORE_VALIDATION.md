# LAB-08 — Restore-Point Validation

**Role:** Recovery engineer

## Objective
Select candidate recovery points without contaminating evidence or trusting unverified media.

## Tasks
- Rank candidate restore points.
- Define hash, readability, consistency, and application-level validation checks.
- Design a clean-room restore test.
- Identify which backups should not be used yet.
- Define acceptance criteria before a restored dataset returns to production.

## Deliverable
Restore Validation Procedure.

## Pass standard
A backup is considered usable only after integrity and functional validation.
