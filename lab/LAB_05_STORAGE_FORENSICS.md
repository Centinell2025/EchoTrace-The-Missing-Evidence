# LAB-05 — Storage Forensics

**Role:** Storage forensic engineer

## Objective
Analyze primary-storage degradation without assuming that every later failure shares the same cause.

## Tasks
- Reconstruct FABRIC-A, FABRIC-B, metadata, and volume events.
- Identify the first configuration-related event.
- Compare it with preceding latency.
- Determine when protective read-only mode was activated.
- Explain which datasets may still be logically recoverable even when currently unavailable.
- List storage evidence that should be acquired before repair.

## Deliverable
Storage Failure Analysis.

## Pass standard
The analyst distinguishes pre-existing degradation, configuration changes, and downstream protective behavior.
