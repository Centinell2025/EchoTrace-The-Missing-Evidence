# EchoTrace — Complete Forensic Training Track

The practical track is designed as a progression from evidence intake to enterprise recovery.

1. Evidence Intake & Chain of Custody
2. Outage Triage
3. Windows / Identity Forensics
4. Service Dependency Mapping
5. Storage Forensics
6. Data-Loss Scoping
7. Backup Catalog Forensics
8. Restore-Point Validation
9. Network & Management-Plane Correlation
10. Automation Baseline Analysis
11. AI-Assisted Activity Assessment
12. Timeline Engineering
13. Forensic Recovery Planning
14. Business Continuity / Disaster Recovery
15. Senior Incident Command Capstone

Students must use supplied synthetic evidence only. No destructive actions or malware execution are required.
