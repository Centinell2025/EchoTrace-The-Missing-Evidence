# EchoTrace — 100 Scenario Laboratory Map

Every ET scenario has a practical lab assignment. Scenarios sharing a forensic technology use a common lab environment but require a different incident hypothesis and deliverable.

| Scenarios | Laboratory environment | Practical work |
|---|---|---|
| ET-001–005 | Synthetic SQL Server case DB | transaction/log/object reconstruction |
| ET-006–010 | SQL audit + agent evidence | audit gaps, jobs, cross-database correlation |
| ET-011–015 | SQL security + backup evidence | privilege, snapshots, sensitive access, recovery point |
| ET-016–025 | Offline Windows/NTFS evidence | Event, MFT, USN, Prefetch, Amcache, Registry, PowerShell, RDP |
| ET-026–035 | Synthetic AD evidence | authentication, Kerberos, groups, GPO, replication, recovery |
| ET-036–040 | Synthetic memory-derived artifacts | volatile process/session/network correlation |
| ET-041–050 | DNS/NetFlow/proxy/firewall evidence | network timeline and evidentiary-limit analysis |
| ET-051–060 | Storage/SAN/RAID metadata | failure reconstruction and recoverability |
| ET-061–070 | Backup catalogue/repository evidence | chain validation and clean-room restore planning |
| ET-071–078 | VM/cloud/container evidence | control-plane, snapshot, disk/object and identity correlation |
| ET-079–085 | ORCH-01 automation evidence | baseline deviation and AI-evidence assessment |
| ET-086–095 | Evidence-management workspace | custody, hashes, acquisition, timeline, scope, root cause |
| ET-096–099 | Recovery engineering tabletop | BCDR, dependency restore, executive reconstruction |
| ET-100 | Full EchoTrace evidence set | end-to-end senior forensic capstone |

## Required laboratory deliverable
Each lab produces at least one professional artifact: timeline, evidence register, SQL reconstruction report, identity assessment, network matrix, storage report, backup validation record, data-loss matrix, recovery runbook, or executive report.

## Evaluation
A technically correct conclusion without reproducible evidence citation is incomplete. A student may receive full credit for an inconclusive result when the supplied evidence genuinely cannot support a stronger conclusion.
