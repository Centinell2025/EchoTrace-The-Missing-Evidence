# EchoTrace — Three Forensic Laboratory Environments

This training is organized into three **student-facing** environments. All activities are defensive and must be performed on supplied synthetic evidence or authorized isolated systems.

1. [Kali Linux Forensic Workstation](01_KALI_LINUX/README.md): evidence intake, hash verification, SQL analysis, cross-source timeline and backup triage.
2. [IoT Device Forensics](02_IOT_DEVICES/README.md): device telemetry, firmware metadata, gateway logs, timestamps, recovery and acquisition constraints.
3. [Windows & Linux Enterprise Forensics](03_WINDOWS_LINUX/README.md): Windows event and NTFS artifacts, Linux journal/authentication, SQL and enterprise outage correlation.

The 25 existing ET-LAB modules remain the competency catalogue. These environments are **execution tracks**, not 25 additional validated labs. Where evidence has not yet been produced, it is explicitly labeled pending.

## Common deliverable
For each exercise provide an evidence register, SHA-256 manifest, normalized timeline, record-level citations, hypotheses, limitations, and preservation/recovery decision.

Instructor solutions remain under `instructor/solutions/` and must not be packaged with student material.
