# SQL Forensic Practice — Evidence-Based Questions

1. Which recorded transaction is committed, which is rolled back, and which remains unknown?
2. What is the difference between an accepted metadata operation and a confirmed durable change?
3. Which backup catalog entries do not correspond to intact repository objects?
4. Which data states indicate unavailability rather than proven permanent loss?
5. Which audit records share a correlation ID with unusual orchestration?
6. What independent evidence is required before attributing a service-account action to a human?
7. Which dataset has the strongest candidate recovery object, and what additional test is still needed?
8. How would you preserve this SQLite training dataset and record its SHA-256 hash?
9. What evidence would native SQL Server LSN/MDF/LDF analysis add that this dataset lacks?
10. Prepare a report distinguishing observation, inference, hypothesis and unsupported assertion.

**Instructor note:** Keep record-level answers and grading key outside the public student repository.
