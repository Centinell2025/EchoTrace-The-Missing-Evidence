# ET-LAB-21 — Cloud Object and Audit Forensics

**Level:** Senior / Insane | **Discipline:** Digital Forensic Technology

## Case
A fictional Northstar Research Systems investigation has incomplete, sometimes contradictory evidence after an enterprise outage. This laboratory focuses on cloud object and audit forensics.

## Objective
Correlate fictional object versions, control-plane events and identity activity.

## Laboratory procedure
1. Record evidence provenance, time basis and acquisition limitations.
2. Identify the relevant supplied synthetic artifacts; list missing artifacts as collection requirements.
3. Preserve original evidence and conduct read-only analysis or work on verified copies.
4. Build a timestamped, record-level timeline.
5. Correlate independent evidence sources where available.
6. Evaluate at least two competing explanations and state confidence.
7. Develop a preservation, validation or recovery decision supported by the findings.

## Five investigation questions
1. What event first supports the working hypothesis?
2. Which artifact, record and UTC timestamp establish it?
3. What second source supports or contradicts the finding?
4. What uncertainty prevents a stronger conclusion?
5. Which safe next investigative or recovery action is justified?

## Ten investigation paths
Consider event logs, SQL transaction evidence, file-system metadata, storage/snapshots, backup chain, network telemetry, identity, application telemetry, independent collections, and isolated recovery validation. Mark inapplicable paths N/A with justification; never fabricate findings.

## Required deliverable
Cloud evidence provenance report. Include evidence citations, exact record identifiers, methodology, competing hypotheses, confidence, limitations and professional recommendations.

## Grading
Provenance 25%; technical analysis 30%; correlation 20%; recovery judgment 15%; reporting 10%.

**Student-safe notice:** All evidence is fictional/synthetic. Instructor answer keys and HTB writeup must not be included in a public student package.
